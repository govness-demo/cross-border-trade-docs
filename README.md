# Cross-border trade documents connector

Connector for exchanging certificates of origin and trade documents between participating customs systems.

## Overview

Implements the shared document schema used by participating customs administrations, so agents can check a certificate's status across borders.

## Interfaces

Protocol: `openapi`. Languages: en, fr.
